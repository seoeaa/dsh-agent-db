# Changelog

## 0.1.0 — 2026-10-21

- First public release: eight native Harness tools for session-owned PGX databases.
- Per-database SQL roles, explicit session sharing, sliding leases and JSON/CSV export.
- Bounded SQL execution, cancellation and identity checks before cleanup.
- Portable bundle configuration and helper for linking the installed Harness runtime peers.
- Validated against Harness 0.2.1-alpha.3 and PGX 0.1.0-beta.1 with live agent/subagent workflows.
